# Cenozoic Silicate Weathering and Carbon Isotope Dynamics
## Project Overview
This project investigates the statistical relationship between silicate weathering 
(proxied by seawater ⁸⁷Sr/⁸⁶Sr) and carbon cycle dynamics (proxied by benthic δ¹³C) 
over the Cenozoic (0–66 Ma).
**Research Question:** Is there a statistically significant relationship between 
seawater ⁸⁷Sr/⁸⁶Sr and benthic δ¹³C, and what is the estimated lag time between 
weathering changes and carbon isotope responses?
